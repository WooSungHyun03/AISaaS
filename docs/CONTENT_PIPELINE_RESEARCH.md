# 콘텐츠 파이프라인 조사와 선택 (2026-10-11)

블로그·숏폼을 가게/상품/플랫폼별로 만드는 방법을 어떻게 정했는지 한 장으로 정리합니다. 가격은 조사 시점(2026-10) 공개 가격이고
결제 전에 다시 확인하세요. 환율은 1달러 ≈ 1,400원으로 계산했습니다.

## 1. 마케팅 콘텐츠 구조 (구성만 참고, 타인의 글·영상을 복제하지 않음)

| 대상 | 검색자/시청자가 하려는 일 | 글·영상이 꼭 답해야 하는 것 | 마무리(CTA) |
|---|---|---|---|
| 가게 | 근처에서 가도 될 곳 확인 | 지역·상황 → 고객 고민과 해결 → 공간·이용 경험 → 믿을 이유 → 오는 길·예약 | 예약·방문·문의 |
| 상품 | 문제를 풀 물건을 비교·결정 | 문제 장면 → 해결 방식 → 사용 장면 → 특징이 주는 가치 → 맞는 사람 → 구매 방법 | 구매 주소 |
| 플랫폼 | 번거로운 일을 줄일 도구 탐색 | 사용자 불편 → 단계별 해결 → 화면·기능 시연 → 대상 → 시작 방법 | 가입·무료 체험 |

코드: `src/server/promotion/strategy.ts` (유형별 검색 의도, 각도, 글 구성 순서, 숏폼 스토리라인, 금지 주장). 네이버는 C-Rank·D.I.A.,
복사·키워드 반복·광고 표시 없는 AI 문장을 낮게 평가하고, 티스토리는 구글 검색에 노출되므로 시맨틱 소제목과 초반 답이 중요합니다
(근거 링크는 `docs/BLOG_QUALITY.md`). 숏폼은 첫 1~2초 훅, 한 가지 메시지, 구체적인 장면, 마지막 장면에서 할 일 안내가 공통입니다.

## 2. 기술 후보 비교

| 영역 | 후보 | 품질(한국어) | 비용/건 | 라이선스·운영 | 판단 |
|---|---|---|---|---|---|
| 글 생성 | Claude Haiku 4.5 (기본) / Sonnet 5.5 (`AI_QUALITY_MODEL`) | 좋음 / 더 자연스러움 | 글 1편 약 9회 호출 ≈ 수십 원 / 수백 원 | API, 상업 이용 가능 | **Claude 유지**, 품질 필요 시 Sonnet만 켬 |
| 이미지→영상 | fal.ai Kling 2.5 Turbo Pro | 사진 움직임 안정적 | 5초 $0.35 (+초당 $0.07) | 유료 API, 선불 | **기본 선택** |
| | Kling 3.0 / Seedance 2.0 / Veo 3.1 | 더 좋지만 비쌈, 입모양·한국어 보고 엇갈림 | Seedance 2.0 ≈ 초당 $0.30, Veo 3.1 Fast ≈ 초당 $0.10~ | 유료 API | 베이크오프 후 결정 (`npm run bakeoff:animation`) |
| 한국어 음성 | Azure ko-KR Neural(JSON2Video 내장) | 자연스러움 충분 | 렌더 비용에 포함 | 상업 이용 가능 | **선택** |
| | ElevenLabs | 가장 자연스러움 | 백만 자당 $100~300 | 유료 | 보류(품질 요구 시) |
| 배경음악 | fal Lyria 2 | 보컬 없는 곡 생성 | 곡당 약 $0.10 | 생성물 상업 이용 | **선택** (저작권 걱정 없는 생성곡) |
| 영상 합성 | JSON2Video (템플릿 없이 JSON 전송) | 9:16, 음성·클립 합성 | 영상 1초 ≈ 1크레딧 | 서버리스 호출만 필요 | **선택** |
| | Remotion | 자유도 최고 | 직접 렌더 서버 필요 | **직원 4명 이상 회사는 유료 라이선스**(자동화 렌더당 $0.01, 월 최소 $100) | 렌더 서버가 필요해 보류 |
| | FFmpeg 직접 | 자유도 높음 | 서버 필요 | LGPL/GPL 주의 | Vercel 무료 환경에서 장시간 렌더 불가 → 제외 |

선택 이유: Vercel/Supabase 무료 구성에서 GPU·장시간 렌더를 돌릴 수 없으므로 **합성은 외부 API(JSON2Video), 움직임은 fal.ai**로 맡기고,
앱은 계획·검수·저장만 합니다. 사용자의 실제 사진(상품·매장·서비스 화면)을 살려 움직이는 방식이 AI가 새로 그린 영상보다 안전하고
광고 심의에도 유리합니다. 사람 사진은 움직이지 않고, 자막은 쓰지 않습니다(요청 사항).

## 3. 이용권 가격 대비 예상 원가 (참고 계산)

| 상품 | 원가 구성 | 원가 | 판매가(현재 설정) | 마진 |
|---|---|---|---|---|
| 블로그 1편 | Claude 약 9회 호출 | 약 70원(Haiku) ~ 350원(Sonnet) | 1,500~1,980원/회 | 약 75~95% (Haiku) |
| 숏폼 1편(상품·매장 홍보, 움직이는 클립 4개) | Kling 4×$0.35 + 음악 $0.10 + 렌더 ≈ $0.5 + 기획 | 약 $2.1 ≈ 2,950원 | 5,300~6,633원/회 | 약 44~56% (PG 수수료 전) |
| 숏폼 1편(캐릭터 5~6클립) | 클립 $1.75~2.1 + 음악 + 렌더 | 약 $2.5 ≈ 3,500원 | 5,300~6,633원/회 | 약 34~47% |

주의: 가입 체험 이용권(블로그 1·숏폼 1)은 원가가 그대로 비용입니다. 숏폼 체험은 건당 약 3천 원이라 어뷰징이 걱정되면
`src/server/billing/products.ts`의 `FREE_TRIAL_CREDITS.amounts.SHORTS`를 0으로 낮추세요.
가격·수량·유효기간은 `PRODUCT_CONFIGS` 한 곳에서만 바꿉니다.

## 4. 비용·실패 보호

- 이용권은 만들기 시작 시 예약 → 성공하면 확정, 실패·중단이면 자동 환원(`complete_automation_run_credit`, 중단된 작업 정리 시 환원).
- 영상 제작 서비스(JSON2Video)가 연결되지 않은 운영 환경에서는 숏폼 시작 자체를 거절합니다(`preflight`): 이용권도 쓰지 않습니다.
  테스트 환경의 가짜 영상은 "테스트용 샘플"로 표시하고 게시를 막습니다.
- 움직이는 클립은 숏폼 1편당 최대 4~6개로 제한, 클립 하나가 실패하면 같은 품질로 1회 재시도 후 기본 효과로 대체.

## 5. 이번에 실제 영상을 만들어 검증했는가

**아니요.** fal.ai·JSON2Video·Anthropic 키가 이 개발 환경에 없어 실제 렌더는 하지 못했습니다. 영상 JSON(JSON2Video 스키마)과 프롬프트는
단위 테스트로 검증했고, 키를 넣은 뒤 `npm run check:providers`로 연결을, `npm run bakeoff:animation`으로 모델별 품질·비용을 확인하세요.
첫 실제 렌더에서 확인할 것: 클립 반복/자르기 동작, 마지막 카드 위치, 한국어 음성 자연스러움.
